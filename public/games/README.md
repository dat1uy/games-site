# Game Portal Setup

This folder is for your HTML game builds.

Use one folder per game:

public/games/
  eaglercraft/
    index.html
    assets/

Or upload a ZIP file such as:

public/games/mygame.zip

The server will extract it into:

public/games/mygame/

Then you can open:

/game/mygame

Do not forget the main file should be named `index.html`.
